# cell-cycle-deconv
Code to deconvolve cell cycle transcription using branching processes and CLOCCS parameters

Refer to: deconvolution.cs.duke.edu

# Usage:
`main.m` - Run deconvolution against all genes from the Xin Guo, 2011 paper.
`mainSingleGene.m` - Run deconvolution against a single gene from the Xin Guo, 2011 paper.
